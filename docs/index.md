## Getting Started

```bash
# 1. Configure .env (DATABASE_URL, NEXTAUTH_*, AWS_*, OPENAI_API_KEY, EVOLUTION_*, SMTP_*)
# See development-guide.md for the full list.

# 2. Option A — Docker
docker-compose up -d
# App at http://localhost:3001

# 2. Option B — Native
npm install
npx prisma generate
npx prisma db push
npx prisma db seed
npm run dev
# App at http://localhost:3000
```
